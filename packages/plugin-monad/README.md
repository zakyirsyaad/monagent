# @monagent/plugin-monad

MetaMask Agent Wallet Plugin for **Monad A2A Commerce & Trust** (Monad Metropolis Hackathon).

## Commands

- `mm monad pay`: Send direct native MON or token micro-payment on Monad.
- `mm monad identity register`: Register an ERC-721 Agent ID on Monad's ERC-8004 Registry.
- `mm monad identity get`: Lookup an agent card and wallet address on Monad.
- `mm monad reputation check`: Query counterparty reputation track record and calculate trust tier.
- `mm monad reputation give`: Submit immutable on-chain review & rating feedback.
- `mm monad x402 pay`: Execute paid API / tool call over HTTP 402 with Monad micropayments.
- `mm monad jobs create`: Fund subcontracted task escrow on Monad.
